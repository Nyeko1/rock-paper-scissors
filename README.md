# Rock-Paper-Scissors Game 🎮✊📄✂️

This is a simple browser-based Rock-Paper-Scissors game built with HTML and JavaScript. The player goes head-to-head against the computer in a 3-round game. User input is collected through prompts, and the computer makes random choices each round.

---

## 🧠 How It Works

- The player is prompted to enter either `rock`, `paper`, or `scissors`.
- The computer randomly selects one of the three choices.
- A winner is declared each round based on classic rules:
  - Rock beats Scissors
  - Paper beats Rock
  - Scissors beats Paper
- After 3 rounds, the game displays the final score.

## ▶️ How to Play

1. Open `index.html` in a web browser.
2. Click the **"Play Game"** button.
3. A prompt will ask you to enter your move: `rock`, `paper`, or `scissors`.
4. After each round, the result is shown in an alert.
5. After 3 rounds, final scores are displayed.
